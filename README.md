# Amazon Beauty Review NLP Analysis

## Project Overview

This project performs end-to-end Natural Language Processing (NLP) analysis on Amazon Beauty product reviews.

## Features

- Two-stream text preprocessing using spaCy
- Named Entity Recognition (NER)
- TF-IDF Vectorization
- Cosine Similarity Analysis
- Word2Vec Embeddings
- PCA Visualization
- LDA Topic Modeling
- Sentiment Classification
  - MultinomialNB
  - BernoulliNB
  - Logistic Regression

## Dataset

beauty_reviews.csv

Columns:
- review_text
- sentiment

## Technologies

- Python
- spaCy
- Scikit-Learn
- Gensim
- Pandas
- Matplotlib
- Seaborn
